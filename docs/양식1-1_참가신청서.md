### 개요 및 주요 기능(핵심 요약)

중진공 **K-Doctor** 진단·접수 정형화(**기시행**) 위에, 진단 **이후** AX 지원 실행 문서를 만들고 국민제안의 「기초체력·기계판독」을 앱에서 닫는 업무보조 도구입니다. **진단·공고 서식 자체를 대체하지 않습니다.**

**핵심**
1. **AX 지원 과업지시서 작성** — 진단·기초체력 결과를 반영해 목적·범위·산출물·일정·역할·검수기준 초안 생성  
2. **공급사 견적 비교** — 과업 범위 적합도 중심 비교 (단가 차이만으로 부적정 단정하지 않음)

**1단계 고도화 (국민제안 접점)**
3. **Data Fitness 자가진단(8문항)** — 데이터 기록·수집 습관 체크 → 등급(준비됨/보완/기초) → 연수원·K-Doctor 교육 링크 넛지  
4. **표준 CSV 검증** — 기업현황 필수 컬럼·숫자형·파일명(`기업명_사업명_문서종류`) 검사, 빈 템플릿 제공 · 견적 CSV 컬럼 검사

**보조:** K-Doctor 합성 연동, 시스템 현황 분석, 상용 LLM 2종 A/B 비교(이식성).

기술 요약: Streamlit · Solar/Gemini · 합성 샘플 · DB 없음 · GitLab 보안 스캔 통과.
