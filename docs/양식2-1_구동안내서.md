## 3. 구동 방법 (심사 권장 경로)

### A. 클라우드 (권장 · 즉시 구동)

1. https://sme-ai-helper.streamlit.app 접속  
2. 상단 메뉴: **기초체력 → 과업지시서 → 업체 → 견적 → 정책**  
3. **기초체력** → 「보고서 업로드」→ **샘플 보고서** ON → 「기초체력 산출」  
4. **과업지시서** → 기업 정보 확인 → 「표준 RFP 만들기」→ PDF/DOCX 확인  
5. **업체 → 견적(샘플 ON) → 정책** 순으로 확인  

> 시연 화면에는 모델·기업 선택 UI가 없습니다. 기본 시연 기업은 합성 샘플 **한빛정밀**, 기본 모델은 `DEFAULT_MODEL`(기본값 Solar)입니다.

### B. 로컬 (선택)

```bash
git clone https://gitlab.aigov.go.kr/kosme2512042/sme_ai_helper.git
cd sme_ai_helper
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # 필요 시 API 키·DEFAULT_MODEL 설정
streamlit run app.py
```

`http://localhost:8501` 접속.

### C. Docker (선택)

```bash
docker build -t sme-ax-helper .
docker run --rm -p 8501:8501 --env-file .env sme-ax-helper
```

## 4. LLM · 모델 비종속 · 보안

| 이름 | Provider | 기본 모델 ID | 교체 방법 |
|------|-----------|--------------|-----------|
| Solar | Upstage | `solar-pro4` | `DEFAULT_MODEL=Solar` + `SOLAR_*` |
| Gemini | Google | `gemini-2.0-flash` | `DEFAULT_MODEL=Gemini` + `GEMINI_*` |
| Llama | OpenRouter | `meta-llama/llama-3.3-70b-instruct` | `DEFAULT_MODEL=Llama` + `LLAMA_*` |
| GPT | OpenAI | `gpt-4o-mini` | `DEFAULT_MODEL=GPT` + `OPENAI_*` |
| EXAONE | LG AI | `k-exaone_v2.5` | `DEFAULT_MODEL=EXAONE` + `EXAONE_*` |

- 등록·교체: `src/config.py`의 `MODELS` · `.env` / Streamlit `secrets`  
- Solar·Llama·GPT·EXAONE은 OpenAI Chat Completions 호환 경로로 호출  
- **키 없음 → Mock**으로 전 메뉴 시연 가능 (기초체력·정책·업체 카탈로그는 키 불필요)  
- API 키는 깃에 넣지 않음 · 업로드는 세션만 · DB 없음 · 실기업 민감자료 금지(합성 샘플만)

## 6. 기능 사용 순서 (5스텝)

**① 기초체력 — 우리 회사 AX 수준 진단**  
보고서 업로드(또는 설문: 업종→적용영역≤2→해결문제≤2→사업·데이터·운영 문항) → 적용 영역·문제·등급 표시  

**② 과업지시서 — 표준 RFP**  
기초체력 반영 16항목(사업개요~제출서류) 초안 · 생성 프롬프트·원본 JSON 비공개 · 한글 PDF  

**③ 업체** — 적용 영역·과업 키워드 공급사 추천(참고, 계약 보증 아님)  

**④ 견적** — 샘플/업로드 비교(단가 차이만으로 부적정 단정하지 않음)  

**⑤ 정책** — 기술자금·스마트화·지역 AI 대전환 등 개요·일정·신청·문의  

> K-Doctor=진단, 접수 서식=기시행, **sme-ax-helper=진단 이후 실행 문서·연계**.

## 7. 제약 · 오픈소스 안내

- K-Doctor **실 API 전** — 보고서 업로드·합성 데이터로 시연  
- 과업지시서·견적은 **참고 초안**(최종 행정 판단 대체 아님)  
- Cloud 콜드스타트 시 최초 로딩 지연 가능  
- 주요 의존성: Streamlit, httpx, pandas, reportlab, python-docx 등(MIT/BSD 위주) · 한글 PDF용 NanumGothic(OFL) · 상용 LLM은 각사 약관

## 8. 개발 요지 (정식활용 관점)

**문제:** 진단·접수 이후 AX 지원 문서화가 수작업·비표준.  
**해법:** AX 수준 확정 → 표준 RFP → 업체·견적·정책까지 한 흐름.  
**운영:** 핵심 5기능 안정, 코드·환경변수로 모델 교체, 합성 데이터, secrets 분리, GitLab 보안 스캔.
